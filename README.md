# Практическое занятие № 14 — вариант 11

**Тема:** создание графического интерфейса на Python с помощью Tkinter.

Программа `main.py` воспроизводит форму **Contact Us** из образца преподавателя: First Name, Last Name, Email, Website, Password, Password Confirmation, кнопка Sign Up.

## Запуск

1. Откройте папку проекта в PyCharm Community.
2. Запустите `main.py` с помощью Python 3 (Tkinter входит в стандартную библиотеку большинства установок Python для Windows).
3. Заполните поля и нажмите **Sign Up**.

Проверяются обязательность заполнения, формат Email и Website, длина пароля 8–10 символов, совпадение паролей. Программа ничего не отправляет в интернет и не сохраняет пароли.

Образец: https://smashinghub.com/wp-content/uploads/2011/08/html5-forums-14.jpg

**Примечание:** в полученном задании для варианта 11 дана одна картинка формы, без текста о второй задаче. Поэтому реализован интерфейс по указанному образцу.
