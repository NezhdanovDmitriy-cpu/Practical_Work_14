# Отчёт по практическому занятию № 14

**Вариант:** 11  
**Тема:** Составление программ с использованием GUI Tkinter в IDE PyCharm Community  
**Количество часов:** 4

## Цель

Закрепить навыки разработки программ на Python с графическим интерфейсом Tkinter.

## Задание

Реализовать графическую форму по изображению-образцу: https://smashinghub.com/wp-content/uploads/2011/08/html5-forums-14.jpg

## Ход работы

1. Создано окно приложения с заголовком Contact Us.
2. Добавлены шесть полей ввода и кнопка Sign Up.
3. Реализованы проверки введённых данных с помощью `messagebox` и регулярных выражений.
4. Поля паролей скрывают вводимые символы.
5. Исходный код снабжён комментариями и оформлен в соответствии с PEP 8.

## Результат

После запуска открывается форма. При неверном вводе появляется предупреждение, при корректном — сообщение об успешном заполнении. Программа не передаёт данные в сеть.

## Вывод

Освоены создание окна Tkinter, размещение виджетов, обработка нажатия кнопки и проверка пользовательского ввода.

**Примечание:** в предоставленном варианте содержится только ссылка на один образец, поэтому реализована одна форма.
